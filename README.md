# Net-speed-tester

Консольный скрипт на Python для грубой оценки скорости скачивания: делает **10 последовательных** GET-запросов к указанному URL, дожидается полного ответа на каждый, считает среднее время, суммарный объём и скорость.

Зависимостей нет — используется стандартная библиотека Python 3.

## Требования

- Python 3.9+

## Запуск

```bash
python3 speed_test.py <URL>
```

Пример:

```bash
python3 speed_test.py https://httpbin.org/bytes/1048576
```

Или любая тяжёлая картинка / файл по прямой ссылке:

```bash
python3 speed_test.py https://example.com/large-image.jpg
```

Опционально — таймаут одного запроса (секунды, по умолчанию 60):

```bash
python3 speed_test.py https://example.com/large-file.bin --timeout 30
```

## Что печатает скрипт

- время и размер каждого из 10 запросов;
- **среднее время запроса** (секунды);
- **общий объём** скачанных данных (байты / KB / MB / GB);
- **скорость скачивания**.

## Единицы

| Метрика | Единица |
| --- | --- |
| Время запроса | секунды (`s`) |
| Объём данных | байты, далее KB / MB / GB (двоичные: 1 KB = 1024 B) |
| Скорость | **Mbps** — мегабиты в секунду (`1 Mbps = 1_000_000 бит/с`) |

Скорость считается так:

```text
Mbps = (суммарные_байты × 8) / суммарное_время_сек / 1_000_000
```

Это не полноценный speedtest до ближайшего сервера провайдера, а практичный замер «сколько занимает полная загрузка выбранного ресурса» по 10 прогонам подряд.
